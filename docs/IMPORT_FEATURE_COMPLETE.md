# 网络设备导入功能 - 完整使用说明

## 功能概述

设备管理页面新增了网络设备导入功能，采用**两步确认**设计：
1. **第一步**：选择并解析文件
2. **第二步**：确认后批量导入

支持 CSV 和 Excel 格式，自动连接设备、获取信息并保存到数据库。

---

## 完整使用流程

### 步骤 1: 打开导入对话框

1. 进入"设备管理"页面
2. 点击右上角 **"导入网络设备"** 按钮
3. 弹出导入对话框

### 步骤 2: 选择文件

**上传方式**：
- 点击上传区域
- 或拖拽文件到上传区域

**文件格式**：
- ✅ `.csv` - CSV 文件
- ✅ `.xlsx` - Excel 文件
- ✅ `.xls` - Excel 文件

**视觉反馈**：
- 未选择文件：灰色虚线边框
- 已选择文件：绿色边框 + 浅绿色背景，显示文件名

### 步骤 3: 预览设备列表

选择文件后，系统自动解析并显示：

```
┌─────────────────────────────────────┐
│ 发现设备：3              [清除]     │
├─────────────────────────────────────┤
│ 192.168.0.104:5555    [待导入]     │
│ 192.168.0.105:5555    [待导入]     │
│ 192.168.0.106:5555    [待导入]     │
└─────────────────────────────────────┘
```

**状态说明**：
- 🔘 **待导入**（灰色）- 已解析，等待导入
- 🔵 **连接中**（蓝色）- 正在连接设备
- 🟢 **导入成功**（绿色）- 连接并保存成功
- 🔴 **导入失败**（红色）- 连接失败

### 步骤 4: 确认导入

确认设备列表无误后：
1. 点击右下角 **"开始导入"** 按钮（带 ✓ 图标）
2. 系统开始批量处理设备

### 步骤 5: 查看导入进度

导入过程中显示：

```
┌─────────────────────────────────────┐
│ 导入中                    2 / 3     │
│ ████████████░░░░░░░░ 66%           │
├─────────────────────────────────────┤
│ 192.168.0.104:5555    [导入成功]   │
│ 192.168.0.105:5555    [连接中]     │
│ 192.168.0.106:5555    [待导入]     │
└─────────────────────────────────────┘
```

### 步骤 6: 导入完成

#### 情况 A：全部成功 ✅

```
提示：成功导入 3 个设备 ✓
```
- 显示成功提示消息
- 1 秒后**自动关闭**对话框
- 设备已添加到数据库
- 可在设备管理页面查看

#### 情况 B：部分失败 ⚠️

```
┌─────────────────────────────────────┐
│ 失败设备：1                         │
├─────────────────────────────────────┤
│ 192.168.0.106:5555 - 连接超时      │
└─────────────────────────────────────┘

提示：导入完成：成功 2/3 ⚠️
```
- 显示失败设备数量
- 底部红色区域显示失败详情
- **保留对话框**供用户查看
- 可手动关闭或重试

## 文件格式要求

### CSV 文件格式

**示例文件** (`devices.csv`)：
```csv
IP 地址，端口
192.168.0.104,5555
192.168.0.105,5555
192.168.0.106
```

**格式说明**：
- 第一行：标题行（可选，会自动跳过）
- 第一列：IP 地址（**必填**）
- 第二列：端口号（可选，默认 5555）
- 分隔符：逗号 `,`
- 编码：UTF-8

### Excel 文件格式

**示例表格** (`devices.xlsx`)：

| IP 地址 | 端口 |
|--------|------|
| 192.168.0.104 | 5555 |
| 192.168.0.105 | 5555 |
| 192.168.0.106 |      |

**格式说明**：
- 第一行：标题行（可选，会自动跳过）
- 第一列：IP 地址（**必填**）
- 第二列：端口号（可选，默认 5555）
- 支持格式：`.xlsx`, `.xls`
- 工作表：读取第一个工作表

## 技术实现

### 前端技术
- **框架**：Vue 3 + Composition API
- **UI 库**：Arco Design Vue
- **状态管理**：Pinia Store
- **文件解析**：
  - CSV: `TextDecoder` (原生)
  - Excel: `xlsx` 库

### 后端技术
- **ADB 连接**：`@devicefarmer/adbkit`
- **数据库**：SQLite (better-sqlite3)
- **IPC 通信**：Electron Main/Renderer

### 导入流程

```
用户选择文件
    ↓
解析文件内容 (CSV/Excel)
    ↓
显示设备列表预览
    ↓
用户点击"开始导入"
    ↓
循环处理每个设备：
    ├─ ADB connect (连接设备)
    ├─ 等待 1 秒
    ├─ ADB info (获取信息)
    ├─ syncDevices (保存到数据库)
    └─ 更新状态
    ↓
检查失败设备
    ├─ 全部成功 → 提示成功，自动关闭
    └─ 部分失败 → 显示失败详情，保留对话框
```

## 常见问题

### Q1: 为什么选择文件后没有反应？
**A**: 请检查：
1. 文件是否包含有效 IP 地址
2. 文件格式是否正确（CSV 或 Excel）
3. 文件编码是否为 UTF-8
4. 查看控制台错误信息（F12）

### Q2: 导入失败怎么办？
**A**: 失败原因可能包括：
- ❌ 设备不在线
- ❌ IP 地址或端口错误
- ❌ 网络不通
- ❌ ADB 服务未启动
- ❌ 防火墙阻止

**解决方法**：
1. 检查设备网络连接
2. 验证 IP 地址和端口
3. 确保 ADB 服务运行
4. 关闭防火墙或添加例外

### Q3: 可以中途取消导入吗？
**A**: 导入过程中无法取消，需要等待当前设备处理完成。可以关闭对话框停止后续设备导入，但已连接的设备会保留在数据库中。

### Q4: 导入的设备保存在哪里？
**A**: 成功导入的设备保存在设备管理页面的数据库中，可以在设备列表中查看和管理。

### Q5: 支持多少设备批量导入？
**A**: 理论上无限制，但建议每次导入不超过 100 个设备，以保证导入速度和稳定性。

## 开发者说明

### 文件位置
- **组件**：`/src/pages/DeviceManage/DeviceImportDialog.vue`
- **翻译**：`/src/lang/zh-CN.json`, `/src/lang/en-US.json`

### 关键函数
- `onFileChange()`: 处理文件选择
- `parseFileContent()`: 解析文件内容
- `startImport()`: 执行导入流程
- `clearFile()`: 清除文件和设备列表
- `resetImport()`: 重置导入状态

### 状态变量
- `selectedFile`: 当前选中的文件
- `deviceList`: 解析出的设备列表
- `failedDevices`: 失败设备列表
- `processedCount`: 已处理数量
- `isImporting`: 是否正在导入
