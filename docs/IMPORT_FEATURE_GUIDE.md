# 网络设备导入功能使用说明

## 功能概述

设备管理页面新增了网络设备导入功能，支持批量导入 CSV 和 Excel 格式的网络设备列表。

## 使用流程

### 1. 打开导入对话框

1. 进入"设备管理"页面
2. 点击右上角"导入网络设备"按钮

### 2. 选择文件

1. 点击上传区域或拖拽文件到上传区域
2. 支持格式：`.csv`, `.xlsx`, `.xls`
3. 选择文件后，文件名会显示在上传区域，背景变为绿色表示已选择

### 3. 预览设备列表

选择文件后，系统会自动解析文件内容并显示：
- 发现的设备数量
- 设备 IP 地址和端口列表
- 每个设备的状态（待导入）

### 4. 开始导入

1. 点击"开始导入"按钮
2. 系统会逐个连接设备并获取信息
3. 实时显示导入进度
4. 每个设备状态会更新为：
   - 🔵 连接中（蓝色）
   - 🟢 导入成功（绿色）
   - 🔴 导入失败（红色）

### 5. 导入结果

**全部成功**：
- 显示成功提示消息
- 1 秒后自动关闭对话框
- 设备已添加到数据库

**部分失败**：
- 显示失败设备数量
- 在底部红色区域显示失败设备列表和错误原因
- 可以查看失败详情后手动重试

### 6. 清除/重置

- 点击"清除"按钮：清除当前文件和设备列表
- 点击"重置"按钮：重置导入状态，可以重新导入

## 文件格式要求

### CSV 文件格式

```csv
IP 地址，端口
192.168.1.100,5555
192.168.1.101,5555
192.168.1.102
```

**说明**：
- 第一行为标题行（可选，会被跳过）
- 第一列：IP 地址（必填）
- 第二列：端口号（可选，默认为 5555）
- 使用逗号分隔

### Excel 文件格式

| IP 地址 | 端口 |
|--------|------|
| 192.168.1.100 | 5555 |
| 192.168.1.101 | 5555 |
| 192.168.1.102 |      |

**说明**：
- 第一行为标题行（可选，会被跳过）
- 第一列：IP 地址（必填）
- 第二列：端口号（可选，默认为 5555）
- 支持 .xlsx 和 .xls 格式

## 功能特点

✅ **自动连接**：导入后自动连接网络设备  
✅ **批量处理**：支持批量导入多个设备  
✅ **实时反馈**：显示每个设备的连接状态  
✅ **错误处理**：失败设备显示具体错误原因  
✅ **智能提示**：全部成功自动关闭，部分失败保留查看  
✅ **格式支持**：支持 CSV 和 Excel 两种常用格式  

## 常见问题

### Q: 为什么选择文件后没有反应？
A: 请检查文件格式是否正确，确保文件包含有效的 IP 地址。控制台会输出详细的错误信息。

### Q: 导入失败怎么办？
A: 失败设备会显示在底部红色区域，包含具体错误原因。常见原因：
- 设备不在线
- IP 地址或端口错误
- 网络不通
- ADB 服务未启动

### Q: 可以中途取消导入吗？
A: 导入过程中无法取消，需要等待当前设备连接完成。可以关闭对话框停止后续设备的导入。

### Q: 导入的设备保存在哪里？
A: 成功导入的设备会保存在设备管理页面的数据库中，可以在设备列表中查看。

## 技术实现

- **文件解析**：
  - CSV：使用原生 TextDecoder 解析
  - Excel：使用 xlsx 库解析
  
- **设备连接**：
  - 使用 ADB 连接网络设备
  - 自动获取设备信息
  - 同步到设备统一存储

- **状态管理**：
  - 使用 Vue 3 Composition API
  - 响应式状态更新
  - 实时进度显示
