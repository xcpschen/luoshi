## 界面元素说明

### 1. 文件上传区域
- **边框状态**：
  - 未选择文件：灰色虚线边框
  - 已选择文件：绿色实线边框 + 浅绿色背景

- **上传方式**：
  - 点击上传区域
  - 拖拽文件到上传区域
  - 支持多文件选择（`multiple` 属性）

- **文件格式**：
  - ✅ `.csv` - CSV 文件
  - ✅ `.xlsx` - Excel 文件
  - ✅ `.xls` - Excel 文件

### 2. 文件列表（已选择）
每个文件显示为独立条目：
```
┌──────────────────────────────────┐
│ [📄] filename.csv      [✓] [🗑️] │
└──────────────────────────────────┘
```

**元素说明**：
- 📄 文件图标：绿色，表示已选择
- 文件名：显示完整文件名
- ✓ 成功图标：表示文件已解析
- 🗑️ 删除按钮：移除单个文件

**功能**：
- 支持删除单个文件
- 删除后自动重新解析剩余文件
- 所有文件删除后，重置状态

### 3. 信息提示区域（失败情况）
显示条件：`failedDevices.length > 0 && !isImporting`

```
┌──────────────────────────────────┐
│ [⚠️] 失败设备：1                 │
├──────────────────────────────────┤
│ 192.168.0.106:5555 - 连接超时   │
│ 192.168.0.107:5555 - 设备不在线 │
└──────────────────────────────────┘
```

**样式**：
- 边框：红色
- 背景：浅红色
- 图标：红色信息图标
- 文字：红色

**内容**：
- 标题：失败设备数量
- 列表：每个失败设备的 IP、端口和错误原因

### 4. 导入进度区域
显示条件：`isImporting === true`

```
┌──────────────────────────────────┐
│ 导入中              2 / 3        │
│ ████████████░░░░░░ 66%          │
└──────────────────────────────────┘
```

**样式**：
- 边框：蓝色
- 背景：浅蓝色
- 进度条：蓝色渐变

**内容**：
- 文字：导入中
- 计数：已处理 / 总数
- 进度条：百分比进度

### 5. 导入按钮
显示条件：`selectedFiles.length > 0 && !isImporting`

```
[📥 开始导入]
```

**样式**：
- 类型：主按钮（蓝色）
- 尺寸：large
- 图标：导入图标
- 位置：右下角

**状态**：
- 默认：可用（有选中文件且未在导入）
- 导入中：隐藏（显示进度条）
- 导入完成：可用（可重新导入）

## 使用流程

### 步骤 1: 选择文件
```
用户操作：点击或拖拽文件
    ↓
系统响应：
  - 显示文件列表
  - 解析文件内容
  - 更新边框为绿色
  - 显示导入按钮
```

### 步骤 2: 管理文件（可选）
```
用户操作：删除不需要的文件
    ↓
系统响应：
  - 移除文件
  - 重新解析剩余文件
  - 更新设备总数
```

### 步骤 3: 开始导入
```
用户操作：点击"开始导入"按钮
    ↓
系统处理：
  - 隐藏导入按钮
  - 显示进度条
  - 逐个连接设备
  - 获取设备信息
  - 更新进度计数
```

### 步骤 4: 查看结果

**情况 A：全部成功**
```
系统响应：
  - 显示成功提示
  - 1 秒后自动关闭
  - 设备已添加到数据库
```

**情况 B：部分失败**
```
系统响应：
  - 显示失败信息区域
  - 显示警告提示
  - 保留对话框
  - 可查看失败详情
```

## 技术实现

### 关键变量
```typescript
selectedFiles: File[]      // 选中的文件列表
uploadFileList: any[]      // 上传组件文件列表
deviceList: any[]          // 解析的设备列表
failedDevices: any[]       // 失败设备列表
processedCount: number     // 已处理数量
totalDevices: number       // 设备总数
isImporting: boolean       // 导入中标志
```

### 核心函数
```typescript
onFileChange()       // 文件选择处理
parseAllFiles()      // 解析所有文件
removeFile()         // 移除单个文件
startImport()        // 开始导入
clearFile()          // 清除所有文件
resetImport()        // 重置导入状态
```

### 导入流程
```
1. 验证设备列表
2. 设置导入状态
3. 循环处理每个设备：
   ├─ ADB connect
   ├─ 等待 1 秒
   ├─ 获取设备信息
   └─ 更新状态
4. 统一同步到数据库
5. 检查结果：
   ├─ 全部成功：提示 + 自动关闭
   └─ 部分失败：显示失败列表
```
