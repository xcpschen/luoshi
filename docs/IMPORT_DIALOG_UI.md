## 视觉设计

### 颜色方案

**文件选择区域**：
- 未选择：`border-gray-300` + `bg-transparent`
- 已选择：`border-green-500` + `bg-green-50`
- Hover: `bg-gray-50`

**状态标签**：
- 待导入：灰色 (`color="gray"`)
- 连接中：蓝色 (`color="blue"`)
- 导入成功：绿色 (`color="green"`)
- 导入失败：红色 (`color="red"`)

**进度区域**：
- 背景：`bg-blue-50` (浅蓝色)
- 进度条：蓝色渐变

**失败区域**：
- 边框：`border-red-300`
- 背景：`bg-red-50`
- 文字：`text-red-600`

### 间距规范

```
容器 padding: 16px (p-4)
区块间距：16px (space-y-4)
内边距：
  - 文件选择：24px (p-6)
  - 设备列表：12px (p-3)
  - 进度条：12px (p-3)
  - 失败结果：12px (p-3)
```

### 字体大小

```
标题：16px (text-base)
副标题：14px (text-sm)
正文：12px (text-xs)
小字：10px (text-2xs)
```

## 交互设计

### 文件上传
1. **点击上传**：打开文件选择对话框
2. **拖拽上传**：拖拽文件到上传区域
3. **支持格式**：自动过滤，只显示 CSV 和 Excel 文件
4. **文件验证**：
   - 检查文件是否存在
   - 检查文件格式
   - 检查文件内容是否有效

### 按钮状态

**"清除"按钮**：
- 默认：可用
- 导入中：禁用

**"重置"按钮**：
- 有设备列表且未导入：可用
- 导入中：隐藏

**"开始导入"按钮**：
- 有设备列表且未导入：可用（蓝色主按钮）
- 导入中：隐藏（进度条替代）
- 导入完成：可用（可重新导入）

### 自动行为

**选择文件后**：
1. 自动解析文件内容
2. 显示设备列表预览
3. 更新上传区域样式（绿色）
4. 显示操作按钮

**全部成功后**：
1. 显示成功提示
2. 1 秒后自动关闭对话框
3. 刷新设备管理页面

**部分失败后**：
1. 显示失败设备区域
2. 显示警告提示
3. 保留对话框供查看
4. 可重新导入失败设备

## 响应式设计

### 对话框尺寸
- 宽度：600px（固定）
- 高度：自适应内容
- 最大高度：80vh（自动滚动）

### 列表区域
- 最大高度：40 (160px)
- 超出滚动：`overflow-y-auto`
- 单行高度：自动

### 进度条
- 宽度：100%
- 高度：默认（Arco Design 标准）
- 文字：右侧显示百分比

## 动画效果

### 过渡动画
- 对话框显示/隐藏：淡入淡出
- 区域显示/隐藏：滑动效果
- 状态变化：平滑过渡

### 加载动画
- 进度条：平滑增长
- 状态标签：即时切换
- 按钮 Loading：旋转图标

## 可访问性

### 键盘导航
- Tab: 切换焦点
- Enter: 确认操作
- Esc: 关闭对话框（已禁用，需手动点击关闭）

### 屏幕阅读器
- 所有图标按钮都有 aria-label
- 状态变化有文字说明
- 错误信息清晰可读
