# MVP（最小可行产品）功能清单

## 1. MVP 目标

**目标**：在 6 周内交付可用的核心功能，验证技术路线和用户需求

**核心场景**：录制用户操作 → 回放执行 → 基础测试用例执行

## 3. MVP 技术栈

### 3.1 前端
```
Vue 3.4+          - 核心框架
TypeScript 5.0+   - 类型系统
Electron 28+      - 桌面应用
Canvas API        - 投屏渲染
OpenCV.js         - 图像识别
```

### 3.2 后端（Electron Main）
```
Node.js 20+       - 运行时
better-sqlite3    - 数据库
scrcpy            - 投屏服务
ADB               - 设备管理
```

### 3.3 开发工具
```
Vite 5+           - 构建工具
Vitest            - 单元测试
Playwright        - E2E 测试
ESLint + Prettier - 代码规范
```

## 5. MVP 验收标准

### 5.1 功能验收

| 功能 | 验收标准 | 状态 |
|------|---------|------|
| 设备连接 | 能连接 Android 设备并显示投屏 | ⬜ |
| 投屏显示 | 延迟 < 150ms，帧率 > 30fps | ⬜ |
| Touch 操作 | 点击/滑动执行成功率 > 95% | ⬜ |
| 图像识别 | 识别准确率 > 90%，耗时 < 300ms | ⬜ |
| 录制功能 | 能完整记录操作并生成 JSON | ⬜ |
| 回放功能 | 能成功回放录制内容，成功率 > 85% | ⬜ |
| 测试用例 | 能执行简单测试流程并生成报告 | ⬜ |

### 5.2 性能验收

| 指标 | 目标值 | 测量方式 |
|------|--------|---------|
| 启动时间 | < 3s | 冷启动到主界面 |
| 投屏延迟 | < 150ms | 端到端延迟 |
| 图像识别 | < 300ms | 单张模板匹配 |
| 操作响应 | < 100ms | 指令到执行 |
| 内存占用 | < 800MB | 峰值内存 |
| CPU 占用 | < 50% | 单设备运行时 |

### 5.3 稳定性验收

- ✅ 连续运行 24 小时无崩溃
- ✅ 录制回放 100 次无异常
- ✅ 内存泄漏 < 50MB/hour
- ✅ 错误恢复率 > 90%
