## 1. 快速入门

### 1.1 打开自动化界面

**方法 1**：点击主界面导航栏的"自动化操作"菜单

**方法 2**：在地址栏输入 `/automation` 并回车

---

### 1.2 创建第一个任务（3 分钟上手）

**步骤 1：新建任务**
```
1. 点击右上角的 [新建任务] 按钮
2. 输入任务名称（如："微信自动打卡"）
3. 输入任务描述（可选）
4. 点击 [确定]
```

**步骤 2：录制操作**
```
1. 点击底部标签页的 [录制]
2. 选择要操作的设备
3. 点击 [开始录制] 按钮
4. 在手机上实际操作（如：打开微信 → 点击工作台 → 点击打卡）
5. 点击 [停止录制] 按钮
```

**步骤 3：执行任务**
```
1. 点击底部标签页的 [回放]
2. 选择刚才创建的任务
3. 点击 [开始执行] 按钮
4. 观看自动执行过程
```

**完成！** 🎉 你已经创建了第一个自动化任务！

## 3. 录制操作

### 3.1 开始录制

**步骤**：
```
1. 点击底部标签页的 [录制]
2. 在设备下拉框中选择设备
   - 确保设备已连接
   - 显示为"已连接"状态
3. 点击 [开始录制] 按钮（绿色）
   - 按钮变为红色 [停止录制]
   - 开始显示录制时长
   - 进入录制状态
```

**界面状态**：
```
┌─────────────────────┐
│ 🔴 录制中           │
│                     │
│ 时长：00:15         │
│ 操作：8 个          │
│                     │
│ [停止录制 (8)]      │
└─────────────────────┘
```

---

### 3.2 录制过程

**操作方法**：
```
在手机上正常操作，系统会自动记录：
✓ 点击操作 → 记录坐标
✓ 滑动操作 → 记录起点和终点
✓ 文本输入 → 记录输入内容
✓ 等待时间 → 记录间隔时长
```

**实时显示**：
```
已录制步骤：
1. 点击 (100, 200)
2. 点击 (300, 400)
3. 滑动 (200,500 → 200,200)
4. 输入 "你好"
5. 等待 2 秒
...
```

---

### 3.3 停止录制

**步骤**：
```
1. 点击 [停止录制] 按钮（红色）
   - 录制停止
   - 显示录制结果
2. 查看录制的步骤
   - 检查是否有误操作
   - 删除不需要的步骤
3. 保存任务
   - 点击 [保存] 按钮
   - 输入任务名称
   - 确认保存
```

**删除步骤**：
```
在步骤列表中：
- 找到要删除的步骤
- 点击步骤右侧的 [删除] 按钮
- 确认删除
```

---

### 3.4 录制技巧

#### 技巧 1：慢一点操作
```
建议：
✓ 操作速度适中，不要太快
✓ 每个操作间隔 1-2 秒
✓ 确保页面加载完成再点击
```

#### 技巧 2：避免无效操作
```
避免：
✗ 快速滑动多次
✗ 重复点击同一位置
✗ 无意义的等待
```

#### 技巧 3：使用等待
```
场景：
- 页面加载需要时间
- 网络请求需要等待
- 动画播放期间

方法：
录制时停顿 2-3 秒，系统会自动记录等待时间
```

## 4. 编排步骤

### 4.1 添加步骤

**方法 1：使用工具箱（推荐）**

```
步骤：
1. 点击 [添加步骤] 按钮
2. 弹出工具箱（底部抽屉）
3. 选择操作类型：
   
   常用操作：
   - 👆 点击：在指定位置点击
   - ⏱️ 等待：等待指定时长
   - ⌨️ 输入：输入文本
   
   高级操作：
   - ✋ 滑动：从一个位置滑到另一个位置
   - 📍 长按：长按指定位置
   - 🔘 按键：执行系统按键（HOME/BACK）
   - 🖼️ 图像识别：识别并点击图像
   - 📷 截图：保存当前屏幕

4. 点击操作类型
5. 根据提示配置参数
6. 完成添加
```

---

### 4.2 配置步骤参数

#### 点击操作配置
```
1. 选择"点击"类型
2. 选择坐标获取方式：
   
   方式 1：屏幕拾取器（推荐）
   - 点击 [在屏幕上选择]
   - 在屏幕截图上点击位置
   - 自动获取坐标
   
   方式 2：手动输入
   - 输入 X 坐标
   - 输入 Y 坐标

3. 确认添加
```

#### 滑动操作配置
```
1. 选择"滑动"类型
2. 配置起点：
   - 方式 1：在屏幕上点选
   - 方式 2：手动输入坐标
3. 配置终点：
   - 方式 1：在屏幕上点选
   - 方式 2：手动输入坐标
4. 配置滑动时长（可选）：
   - 拖动滑块调整
   - 范围：100ms - 2000ms
5. 确认添加
```

#### 输入操作配置
```
1. 选择"输入"类型
2. 输入文本内容：
   - 在文本框中输入
   - 支持中英文
3. 选择输入方式：
   - ADB 输入：适合英文
   - 输入法：支持中文
4. 确认添加
```

#### 等待操作配置
```
1. 选择"等待"类型
2. 选择等待类型：
   
   固定时长：
   - 拖动滑块调整时长
   - 范围：0.5 秒 - 30 秒
   - 或点击快速选择：1 秒、2 秒、3 秒、5 秒
   
   条件等待（高级）：
   - 选择等待条件（图像/文本出现）
   - 设置超时时间
   - 系统会自动等待直到条件满足

3. 确认添加
```

---

### 4.3 调整步骤顺序

**拖拽排序**：
```
步骤：
1. 找到要移动的步骤
2. 鼠标移到步骤左侧的 ☰ 图标上
3. 按住鼠标左键
4. 拖动到目标位置
5. 松开鼠标
6. 自动保存新顺序
```

**界面反馈**：
```
拖动时：
- 步骤变为半透明
- 显示目标位置的占位符
- 其他步骤自动让出空间
```

---

### 4.4 编辑步骤

**修改步骤参数**：
```
1. 点击要编辑的步骤
2. 右侧弹出属性面板
3. 修改参数：
   - 坐标
   - 时长
   - 文本内容
   - 等
4. 点击 [保存]
```

**删除步骤**：
```
方法 1：
- 点击步骤右侧的 [删除] 按钮
- 确认删除

方法 2：
- 选中步骤
- 按 Delete 键
- 确认删除
```

**复制步骤**：
```
1. 右键点击步骤
2. 选择 [复制]
3. 在目标位置右键
4. 选择 [粘贴]
```

---

### 4.5 步骤管理技巧

#### 技巧 1：给步骤命名
```
建议：
✓ 给重要步骤添加名称
✓ 使用描述性名称（如："点击登录按钮"）
✓ 方便后续识别和调试
```

#### 技巧 2：添加备注
```
场景：

方法：
在步骤属性面板的"备注"字段中输入
```

#### 技巧 3：合理分组
```
建议：
✓ 相关步骤放在一起
✓ 使用等待步骤分隔不同阶段
✓ 保持逻辑清晰
```

## 6. 常见问题

### Q1: 录制时没有记录到操作？

**可能原因**：
- 设备未正确连接
- 未选择设备
- 录制未真正开始

**解决方法**：
```
1. 检查设备连接状态
   - 确保设备显示"已连接"
2. 在设备下拉框中选择设备
3. 确认录制按钮变为红色
4. 重新尝试录制
```

---

### Q2: 回放时点击位置不准确？

**可能原因**：
- 屏幕分辨率变化
- 设备方向改变
- 坐标记录错误

**解决方法**：
```
方法 1：重新录制
1. 删除不准确的步骤
2. 重新录制该操作
3. 确保设备位置固定

方法 2：手动调整
1. 选中该步骤
2. 在属性面板修改坐标
3. 保存并重新测试
```

---

### Q3: 如何编辑已保存的任务？

**步骤**：
```
1. 在任务列表中点击任务
2. 切换到 [编排] 标签页
3. 编辑步骤：
   - 添加新步骤
   - 删除步骤
   - 修改步骤参数
   - 调整顺序
4. 点击 [保存] 按钮
```

---

### Q4: 如何删除任务？

**方法 1**：
```
1. 在任务列表中找到任务
2. 右键点击任务
3. 选择 [删除]
4. 确认删除
```

**方法 2**：
```
1. 选中任务
2. 按 Delete 键
3. 确认删除
```

---

### Q5: 如何复制任务？

**步骤**：
```
1. 选中要复制的任务
2. 切换到 [编排] 标签页
3. 点击 [另存为新任务]
4. 输入新任务名称
5. 确认保存
```

---

### Q6: 执行速度太快/太慢？

**调整执行速度**：
```
1. 在 [回放] 标签页
2. 点击 [执行设置]
3. 调整速度滑块：
   - 0.5x：慢速（适合调试）
   - 1.0x：正常（推荐）
   - 1.5x：快速
   - 2.0x：倍速
4. 保存设置
```

---

### Q7: 如何处理需要登录的场景？

**方案 1：录制登录过程**
```
1. 从头开始录制
2. 执行完整的登录流程
3. 保存为"登录"任务
```

**方案 2：手动添加登录步骤**
```
1. 在任务开始添加步骤：
   - 点击输入框
   - 输入用户名
   - 点击密码框
   - 输入密码
   - 点击登录按钮
2. 添加等待步骤（等待登录完成）
```

---
